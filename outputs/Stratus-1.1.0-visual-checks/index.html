VanillaTweaks version mismatch

The supplied VanillaTweaks archive targets resource formats 84–97 (Minecraft 26.1–26.3), while Minecraft 1.21.11 uses format 75. Its black firefly model reproduced with shaders disabled. The separate compatibility pack selects the vanilla bush model and was enabled above VanillaTweaks for QA. A VanillaTweaks build for 1.21.11 is the preferred replacement.
