Stratus 1.0.6 · actual Minecraft visual checks

16 October 2026. Minecraft 1.21.11, Iris 1.10.8, Sodium 0.8.14, Apple M1, Reference preset. Final run: zero shader errors. Native offline compile/link: 432 passes. These are unretouched Minecraft screenshots from a copied singleplayer world.

Use Stratus-1.0.6.zip in Shader Packs. Enable Stratus-Firefly-Compatibility-1.21.11.zip above VanillaTweaks in Resource Packs. The compatibility pack contains one model-selection override and no textures.

Entity shadows

Circular vanilla shadow removed. Game entity-shadow option stayed enabled.

Ore dampness

Ore host stone now uses the same dampness as neighboring stone or deepslate.

Firefly bush compatibility

The 26.1–26.3 VanillaTweaks model is incompatible with this 1.21.11 instance. A separate resource pack restores vanilla bush models.

Firefly diagnosis with shaders disabled

The black planes remained with shaders disabled, confirming a resource-pack compatibility problem. The patch restores vanilla plant cutouts while retaining the rest of VanillaTweaks.

Additional visual checks

Ore and shadow baselines used vanilla assets; final captures use VanillaTweaks plus the compatibility patch. Pool bottom and scene props were improved during testing, so unrelated pool appearance is not a controlled comparison. No FPS benchmark or full normal-profile mod-stack test.
