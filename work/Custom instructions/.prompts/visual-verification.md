# In-game visual verification

For review-only requests, inspect and report; do not modify shader source or install another build without an implementation request.

1. Confirm the intended Minecraft profile, loaded shader pack/build and actual shader options. A ZIP existing on disk does not prove it loaded.
2. Choose a scene that demonstrates the requested effect. Use a normal world for natural terrain and water comparisons; use fixtures when precise geometry helps.
3. Match camera, resolution, render distance, weather, time and options for before/after comparisons.
4. Inspect screenshots or the live game for the requested result and nearby regressions. Check camera placement is valid and not inside terrain.
5. Record evidence paths, environment and findings. Check logs for relevant load/compile errors when available.
6. Report each state accurately: source checked, compiled, packaged, installed, loaded, visually reviewed, performance measured. Mark unavailable checks pending.

Do not certify a visual result from compile logs, automated GPU checks, generated concepts or historical screenshots alone.
