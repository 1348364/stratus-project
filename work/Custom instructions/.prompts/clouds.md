# Clouds and atmosphere workflow

Apply this workflow to the cloud or atmosphere brief in TASK.md.

1. Inspect the reference and current cloud pipeline, lighting, temporal behaviour and quality settings.
2. Preserve the requested composition, cloud character and atmosphere. Change only the requested elements.
3. Balance cloud shape, scale, coverage, softness, lighting and traversal cost. Preserve existing vanilla/custom modes when present unless the brief changes them.
4. Inspect daylight, sunset and motion for banding, flicker, ghosting, horizon seams and distracting patterns. Include weather/night only where affected.
5. Compare quality and performance with matched settings. Record what was actually rendered and any remaining checks.
