# Five-effect public experience

2026-10-23. Original Stratus composition inspired by the cinematic depth and scroll storytelling of igloo.inc.

## Spatial systems

1. Pointer-reactive floating voxel sculpture (17 procedural CSS blocks).
2. Scroll-unfolded water, light and atmosphere planes.
3. Pointer-driven perspective on feature cards and showcase images, with keyboard focus treatment.
4. Release-image depth carousel with previous/next, arrow keys, side-plane selection and the existing full-image lightbox.
5. Scroll-reactive extruded Stratus wordmark.

## Choreography and layout

Eight reveal families: heading masks, tracking, rising cards, line wipes, image crops, alternating release slides, soft dissolves and staggered details. Existing fog, page transitions, reading progress, FAQ, buttons and form focus treatments remain. The visual hierarchy has more whitespace and fewer overlapping hero annotations.

New gallery items from the release feed receive the carousel layout and reveal observation. Decorative layers follow the live hero image. Motion control and operating-system reduced motion disable movement. Hero animation pauses offscreen and in hidden tabs. Native scrolling is retained.
